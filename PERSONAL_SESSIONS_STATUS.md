## How It Works Right Now

**For Sales Team Members:**
1. Get your personal URL: `https://presentations.stmath.com/conv-tool-{your-name}`
2. Print QR code (generated by seed script)
3. Put QR code at conference booth
4. Attendees scan → auto-join your session

**For Attendees:**
1. Scan QR code or visit personal URL
2. System looks up session mapping in Firebase
3. Auto-joins the session (no code entry needed)
4. Sees waiting screen until presenter navigates to activities

**Current Limitations (MVP):**
- Sessions must be manually created in Firebase first
- Still need to use extension or manually create session for presenter side
- No display-only mode yet (all activities are interactive)
- No presenter presence detection yet
- No admin dashboard yet

**Option A: Use Extension (Easier)**
1. Open Conversation Tool in browser
2. Click extension → Create Session
3. Note the session code (e.g., "ABC123")
4. In Firebase Console, update `/personalSessions/james/sessionCode` to match

**Option B: Direct Firebase (More Manual)**
1. Run seed script to get session codes
2. Create session in Firebase `/sessions/{code}` with structure:
